# logistics.postech.ac.kr

Site for POSTECH Logistics Lab (served via GitHub Pages).

- Keep **exact legacy paths and file names** (case-sensitive, `.htm` vs `.html`) — they are cited in published papers.
- Files < 100 MB go in the repo; larger datasets go to **Releases** and are linked from the page. Do not use Git LFS.
- Unknown paths fall back to `404.html`.
- Data files (zip, txt, pdf) are byte-identical to the backups. Legacy Word-exported HTML pages were re-encoded from `ks_c_5601-1987` to UTF-8, because GitHub Pages always serves `charset=utf-8`.
